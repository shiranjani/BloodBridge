# Blood Donation System - Folder Explanation

This file explains why each main folder and file exists in this project.

## Root Folder

- `src`
  - This is the active React app source folder.
  - Most project edits should happen inside this folder.

- `public`
  - Static files for the active React app.
  - Edit only when changing icons, HTML metadata, or public assets.

- `package.json`
  - Stores project dependencies and run commands.
  - `npm start` runs the React frontend.
  - `npm run server` runs the backend server.
  - `npm run build` creates the production build.

- `package-lock.json`
  - Locks the exact installed npm package versions.
  - This helps the project install the same versions on every machine.

- `.env.example`
  - Shows the environment variables needed by the backend.
  - Copy this file to `.env` and add your MySQL username and password.

- `server.js`
  - Contains the Express backend code.
  - Connects to the MySQL database.
  - Handles API endpoints for users, donors, blood requests, and inventory.

- `README.md`
  - Contains setup and run instructions for the project.

- `react.log`, `react-error.log`, `server.log`, `server-error.log`
  - Local debug log files.
  - These help check frontend or backend errors.

## `src`

This folder contains the main React frontend source code.

- `src/index.js`
  - The React entry point.
  - It mounts the React app into the browser page.

- `src/App.js`
  - The main frontend application file.
  - It now works as the small app controller.
  - It manages screen navigation and login/logout state.
  - It imports each page from the separate page folders.

- `src/App.css`
  - The main stylesheet for the app.
  - It styles the landing page, login/register pages, dashboards, forms, tables, and responsive layouts.

- `src/index.css`
  - Global base styles for the browser page.

- `src/assets`
  - Stores images and other visual assets.
  - Login, register, and home page images are kept here so React can bundle them correctly.

- `src/components`
  - Stores reusable UI components.
  - Examples: `AuthForm`, `BloodRequestForm`, `DashboardLayout`, `InfoCard`, `Metric`, `SiteFrame`, `StatusBadge`, and tables.

- `src/pages`
  - Stores full page/screen components.
  - `src/pages/public` stores public pages such as Home, About, Contact, and Chat Support.
  - `src/pages/auth` stores Login and Register pages.
  - `src/pages/donor` stores donor dashboard and donor notifications.
  - `src/pages/admin` stores the admin dashboard and admin management sections.
  - `src/pages/BloodRequestScreen.jsx`, `src/pages/DonorSearch.jsx`, and `src/pages/ProfileView.jsx` are shared app pages.

- `src/services`
  - Stores API helper code.
  - `src/services/api.js` contains the shared `apiFetch` function used by pages and components.

- `src/data`
  - Stores static app data.
  - Navigation menu definitions and sample request rows are kept here.

- `src/utils`
  - Stores reusable logic that is not UI.
  - `src/utils/inventory.js` contains the expiry alert calculation.

## `public`

This folder contains static public files and the HTML template.

- `public/index.html`
  - The base HTML file loaded by the browser.
  - React renders the app inside this file.

- `public/favicon.ico`, `logo192.png`, `logo512.png`
  - Browser tab icon and app icons.

- `public/manifest.json`
  - App metadata used for installable/PWA behavior.

- `public/robots.txt`
  - Search engine crawler rules.

## `build`

- Production build output.
- This folder is generated by `npm run build`.
- Do not edit this folder manually. Edit source files and rebuild instead.

## `node_modules`

- Installed npm packages.
- Do not edit this folder manually.
- If it is missing, run `npm install` to recreate it.

## `blood-ui`

- Looks like a separate or older React app copy.
- The current active app is in the root `src` folder.
- For main development, use root `src`, `server.js`, and `package.json`.
- Do not edit this folder unless you intentionally want to work on the older copied app.
